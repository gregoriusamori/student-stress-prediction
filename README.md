# Student Mental Health Early Detection System

Aplikasi web untuk deteksi dini tingkat stres dan kesehatan mental mahasiswa berbasis web statis yang di-host menggunakan **Hugging Face Spaces**.

---

## 📌 Deskripsi Proyek
Proyek ini dikembangkan sebagai bagian dari tugas mata kuliah **Cloud Computing** di **Universitas Sari Mulia (UNISM)**. 

Aplikasi ini bertujuan untuk memberikan fasilitas asesmen mandiri (*self-assessment*) bagi mahasiswa dalam mengevaluasi tingkat stres akademik secara cepat, responsif, dan interaktif melalui browser tanpa memerlukan proses backend server yang rumit.

## 🛠️ Teknologi & Infrastruktur Cloud
* **Cloud Platform:** Hugging Face Spaces (Static SDK)
* **Frontend:** HTML5, CSS3, & JavaScript (Vanilla JS)
* **Deployment Method:** Direct Web UI Editor / Git Repository

---

## 📋 Fitur Utama
1. **Kuisioner Interaktif:** Pertanyaan seputar beban tugas, kualitas tidur, dan kecemasan akademik.
2. **Kalkulasi Otomatis:** Algoritma skoring langsung di sisi klien (*client-side*) menggunakan JavaScript.
3. **Indikator Hasil Visual:**
   * 🟢 **Tingkat Stres Rendah (Normal)**
   * 🟡 **Tingkat Stres Sedang**
   * 🔴 **Tingkat Stres Tinggi**

## 🚀 Cara Menjalankan Secara Lokal
1. Clone repositori ini atau unduh file `index.html`.
2. Buka file `index.html` langsung menggunakan browser pilihan Anda (Chrome, Edge, Firefox, dll.).
