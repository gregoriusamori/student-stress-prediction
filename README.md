# Deployment Sistem Deteksi Dini Kesehatan Mental Mahasiswa Berbasis Machine Learning

Repositori ini berisi kode sumber untuk Tugas Besar Mata Kuliah **Cloud Computing** Program Studi Sistem Informasi Universitas Sari Mulia.

## Deskripsi Proyek
Aplikasi web berbasis Python (Streamlit) yang menerima kuesioner dari pengguna lalu mengklasifikasikan tingkat stres/kesehatan mental mahasiswa secara otomatis. Aplikasi ini dideploy ke lingkungan cloud menggunakan **Hugging Face Spaces**.

## Teknologi yang Digunakan
- **Bahasa Pemrograman:** Python
- **Framework Web:** Streamlit
- **Cloud Platform:** Hugging Face Spaces (Managed Platform)
- **Version Control:** Git & GitHub
